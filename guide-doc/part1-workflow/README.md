## 🔑 核心概念

- **pyenv**：管理 Python 解释器版本（类似 nvm）
- **uv**：现代的包管理和项目管理工具（类似 npm/pnpm）
- **venv**：虚拟环境，隔离项目依赖
- **pyproject.toml**：项目配置文件（类似 package.json）
- **.venv/**：虚拟环境目录（类似 node_modules/）
