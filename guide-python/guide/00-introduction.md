# 如何阅读这份指南

> 回到 [主页](README.md) 查看完整目录。

这份文档面向**已经有至少一门编程语言经验**的工程师。我们不会从"什么是变量"讲起，而是假设你已经熟悉函数、类、模块、包管理等概念，重点解决 **"Python 里怎么做"** 的问题。

### 0.1 推荐学习路径

按这个顺序阅读，能最快地上手实际开发：

1. **先建立工作流** → 第 1 章「完整开发路径」+ 第 2–5 章
   - 学会用 `uv` 创建项目、运行脚本、安装依赖
   - 理解 `pyenv` / `uv` / `venv` 的关系
   - 了解项目目录结构和跨文件引用方式

2. **理解核心语言** → 第 6–9 章
   - 数据类型、变量、可变性
   - 迭代、枚举、推导式
   - 错误处理

3. **查阅速查表** → 第 10 章
   - 与 JavaScript 的语法对照

### 0.2 文档约定

- 示例中 `JS:` 表示 JavaScript 写法，`Python:` 表示 Python 写法。
- 章节中带 ⚠️ 的为**常见坑点**，建议重点看。
- 带 ✅ 的为推荐做法。
- 每章末尾有「本节要点」，适合快速复习。
