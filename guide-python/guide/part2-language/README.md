## 🔑 核心概念

- **可变 vs 不可变**：理解哪些类型可以原地修改
- **值与引用**：Python 赋值是绑定，不是复制
- **作用域（LEGB）**：名字从内到外的查找顺序
- **引用安全**：可变默认参数、浅拷贝 vs 深拷贝
- **推导式**：Python 风格的 map/filter/reduce
- **生成器**：惰性求值，节省内存
- **异常处理**：try-except-else-finally
- **with 语句**：资源管理的最佳实践
